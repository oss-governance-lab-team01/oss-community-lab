
# RFC-0001: Chuẩn hóa hệ thống Log sang JSON

- Tác giả: @sinh_vien_d
- Trạng thái: DRAFT
- Ngày tạo: 2026-11-23

## 1. Tóm tắt đề xuất (Summary)

Chuyển đổi cơ chế ghi nhật ký hoạt động (Logging)
từ Plain Text sang Structured JSON Logging.

Các trường metadata được chuẩn hóa:
- timestamp
- level
- service
- trace_id

## 2. Động lực thay đổi (Motivation)

Log dạng chuỗi gây khó khăn cho việc phân tích
tự động trên ELK Stack, Grafana Loki hoặc Datadog.

Việc sử dụng Regex để trích xuất thông tin
làm tăng chi phí xử lý và khó bảo trì khi format đổi.

## 3. Phân tích tác động phá vỡ (Breaking Changes)

- Theo giả định RFC, việc đổi định dạng làm các
  parser log bên ngoài không còn tương thích.
- Đề xuất tăng MAJOR từ v1.x.x lên v2.0.0.
- Giảm thiểu tác động bằng biến môi trường:

  LOG_FORMAT=json|text

- Duy trì khả năng sử dụng định dạng cũ
  trong giai đoạn chuyển tiếp 06 tháng.

## 4. Các giải pháp thay thế (Alternatives)

Giữ nguyên text log và xây dựng parser Fluentd riêng.

Không lựa chọn vì:
- Chi phí bảo trì cao.
- Phụ thuộc vào format chuỗi.
- Không giải quyết triệt để khả năng mở rộng.
